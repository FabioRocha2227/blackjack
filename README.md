# Blackjack

## Setup

1. Install Node.js and npm if they are not already on the machine.
2. Optional: install dependencies manually if you want them cached before the first run:

	```bash
	npm install
	```

3. Or just run any npm script. The first `npm` run will bootstrap dependencies automatically if `node_modules` is missing.

## Run in Browser

1. Start the Vite dev server:

	```bash
	npm run dev
	```

2. Open the local URL shown in the terminal.

## Run as Desktop App

1. Start the Electron desktop build:

	```bash
	npm run dev:desktop
	```

2. The app opens in its own Electron window.

## Build and Start Desktop App

1. Build the app:

	```bash
	npm run build
	```

2. Open the built Electron app:

	```bash
	npm start
	```
